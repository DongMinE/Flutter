# GoRouter 버전별 주요 변경사항

## 주요 버전별 변경사항 요약

| 버전 | 출시 시기   | 주요 기능 및 변경사항                                                                                | Breaking Changes                                            |
| ---- | ----------- | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| 7.x  | 2023년 초   | - 기본적인 라우팅 기능<br>- 중첩 라우팅 지원<br>- URL 기반 네비게이션<br>- 간단한 리다이렉션         | -                                                           |
| 8.x  | 2023년 중반 | - 향상된 타입 안정성<br>- 더 나은 에러 핸들링<br>- GoRouterState 개선<br>- 라우트 파라미터 처리 개선 | - 일부 메서드 시그니처 변경<br>- GoRouterState 구조 변경    |
| 9.x  | 2023년 중반 | - 새로운 리다이렉션 API<br>- 라우트 빌더 패턴 도입<br>- 향상된 디버깅 기능                           | - 리다이렉션 로직 변경<br>- 일부 deprecated API 제거        |
| 10.x | 2023년 후반 | - StatefulShellRoute 초기 도입<br>- 더 나은 웹 지원<br>- 향상된 딥링크 처리                          | - 라우트 정의 방식 변경<br>- 네비게이션 API 일부 변경       |
| 11.x | 2023년 말   | - StatefulShellRoute 안정화<br>- 성능 최적화<br>- 더 나은 타입 추론                                  | - ShellRoute 관련 API 변경                                  |
| 12.x | 2024년 초   | - 새로운 라우트 그룹 기능<br>- 향상된 에러 페이지 처리<br>- 더 나은 상태 관리                        | - 라우트 그룹 관련 변경<br>- 일부 deprecated 기능 제거      |
| 13.x | 2024년 초   | - 새로운 미들웨어 시스템<br>- 향상된 로깅 기능<br>- 더 나은 테스트 지원                              | - 미들웨어 구현 방식 변경                                   |
| 14.x | 2024년 초   | - 비동기 가드 지원<br>- 향상된 타입 시스템<br>- 더 나은 코드 분할                                    | - 가드 구현 방식 변경                                       |
| 15.x | 2024년 현재 | - 완전한 타입 안정성<br>- 향상된 성능<br>- 새로운 라이프사이클 훅<br>- Material 3 지원 강화          | - 일부 API 시그니처 변경<br>- 새로운 라이프사이클 적용 필요 |

## 주요 기능별 도입 버전

### 라우팅 기능

- **기본 라우팅**: 7.x
- **중첩 라우팅**: 7.x
- **라우트 그룹**: 12.x
- **StatefulShellRoute**: 10.x (도입) → 11.x (안정화)

### 상태 관리

- **기본 상태 관리**: 7.x
- **향상된 상태 관리**: 12.x
- **라이프사이클 훅**: 15.x

### 보안 및 가드

- **기본 리다이렉션**: 7.x
- **향상된 리다이렉션**: 9.x
- **비동기 가드**: 14.x

### 성능

- **기본 성능 최적화**: 7.x
- **코드 분할 지원**: 14.x
- **향상된 성능 최적화**: 15.x

## 마이그레이션 가이드

### 7.x → 10.x

1. 리다이렉션 로직 업데이트
2. 새로운 라우트 정의 방식 적용
3. 타입 안정성 관련 코드 수정

### 10.x → 13.x

1. StatefulShellRoute 사용 방식 업데이트
2. 새로운 미들웨어 시스템 적용
3. 라우트 그룹 기능 활용

### 13.x → 15.x

1. 비동기 가드 구현
2. 새로운 라이프사이클 훅 적용
3. 타입 시스템 업데이트

## 권장 사항

- 새 프로젝트: 13.x 이상 사용 권장
- 기존 프로젝트: 단계적 업그레이드 (7.x → 10.x → 13.x → 15.x)
- 프로덕션: 안정화된 13.x 버전 권장
